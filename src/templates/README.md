# ForgeKit

Generate your project. Start building.

ForgeKit is a simple command-line tool that helps you quickly create a basic project structure.

## Features

* Create a new project directory
* Choose between C, C++, Python, and Java
* Generate an initial Hello World file
* Create a basic project structure
* Initialize a Git repository

## Supported Languages

* C
* C++
* Python
* Java

## Project Structure

Depending on the selected language, ForgeKit creates a basic structure such as:

```text
my-project/
├── include/
├── src/
│   └── main.c
└── README.md
```

The `include` directory is currently created for C and C++ projects.

## Getting Started

Run ForgeKit and follow the instructions in the terminal:

1. Enter your project name
2. Choose a programming language
3. Choose whether to initialize a Git repository

ForgeKit will create the project structure and an initial source file so you can start building.
